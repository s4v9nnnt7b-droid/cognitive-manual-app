# 自分取説・かんたんタイプ診断 MVP

## URL

- ローカル: `http://localhost:3000/simple`
- 本番反映後: `/simple`

## 実装範囲

- 28問の質問フロー
- 5段階回答
- LocalStorageによる途中保存・再開
- 8つの特性軸を0〜100で算出
- 軸ごとの回答一貫性と確信度
- 8タイプの適合度
- 主タイプ・副タイプ・ハイブリッド表示
- 仕事・勉強、スポーツ、趣味、人間関係の場面別表示
- Web Share API／クリップボード共有
- 初期版であることと非診断の注意表示

## タイプ

1. スプリンター
2. アーキテクト
3. スカウト
4. ダイバー
5. クラフター
6. ナビゲーター
7. コネクター
8. ガーディアン

## 保存

端末の `LocalStorage` に回答、現在位置、画面状態を保存する。サーバーや外部APIへ回答を送信しない。

## 検証項目

- iPhone幅で質問文と選択肢がはみ出さない
- 28問を最後まで回答できる
- 戻る操作で回答が維持される
- 再読み込み後に続きから再開できる
- 8軸、主副タイプ、4場面の結果が表示される
- 共有とリセットが動作する
- 医療診断・能力判定と誤認させる表現がない

## 現時点の制約

- 質問と重みは初期仮説であり、心理尺度として妥当性検証済みではない
- 相性は二人分の比較ではなく、本人側の関係調整ガイド
- 本番ホームからの導線は、実機レビュー後に追加する
